      what a covering is

      Take seven points and these seven lines of three. Pick any two points and one line holds both, so the lines cover every pair. Seven is the fewest that can do it: C(7,3,2) = 7.

      For most sizes nobody knows the fewest. Tables list the best coverings found so far, some unbeaten for decades. A smaller covering is a new record, and one that meets the proven lower bound settles the entry for good. The lab’s first record, C(83,17,2) = 30, did both.

      how the lab works

      1. 1

        A model proposes

        Every fifteen minutes an AI model reads the search program and how it scores, and writes one change to it. Claude Haiku 5.5 tries small changes; once an hour Claude Sonnet 5.5 tries a bolder one.

      2. 2

        A sealed box runs it

        The changed program is compiled and run in a container with no network, on seventeen hard entries with fixed seeds, a minute each.

      3. 3

        The checker decides

        Only coverings the exact checker verifies count. A change stays when it clearly beats the current program on four sets of seeds. Everything else is thrown away.

      4. 4

        The hunt goes on

        The program that won runs on the lab’s server day and night against open entries. A covering that beats the table is checked again, timestamped in Bitcoin and published here.

      check it yourself

      Paste a certificate or drop a file. Your browser runs the same checker that settles the lab’s results, compiled to 60 kB of WebAssembly. Nothing leaves your machine.

      From a terminal, with the code on GitHub:

      cargo run --release -- check records/covering-83-17-2.txt
ots verify records/covering-83-17-2.txt.ots
